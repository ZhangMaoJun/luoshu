# 洛书与幻方

> 3–6 阶幻方的计数、构造与可视化；附后天八卦数理来源的文献考证。

这个仓库做三件事：

1. **把 3–6 阶幻方的数量说清楚**，并区分「证明」与「计算」两种可靠性；
2. **把 4 阶的 880 个本质解完整枚举出来**，附数据和枚举脚本，结果可复现；
3. **考证后天八卦配洛书数的来路**——它不是「卦符合了幻方」，而是两套系统共用同一个九宫坐标系。

## 1. 洛书就是 3 阶幻方

### 1.1 唯一性

3 阶幻方（用 1–9，每行每列两对角线之和相等）本质只有一个解，就是洛书：

```
4 9 2
3 5 7
8 1 6
```

「本质只有一种」的意思是：不考虑旋转和镜像。加上 4 个旋转 × 2 种手性，共 **8 种排布**，它们全部是同一个解的不同朝向。

这一点可以用程序穷举确认（`tools/enumerate.py --order 3`），结果恰好 8 个解、1 个等价类。

### 1.2 中心必为 5（可证明）

穿过中心格的线有 4 条：1 行、1 列、2 条对角线。这 4 条线**恰好覆盖全部 9 个格子**——中心算 4 次，其余 8 格各算 1 次。

4 条线的和是 `4 × 15 = 60`，所以：

```
4c + (45 − c) = 60
3c = 15
c = 5
```

**中心只能是 5**，这一步就把 9! = 362,880 种排法砍掉了一大片。剩下的靠分类排除，最终只剩洛书。

这是一条**演绎证明**，不依赖程序。

### 1.3 8 种排布的结构

8 个变体可以拆成 `4 × 2`：

| 1 的位置 | 手性 | 说明 |
|---|---|---|
| 下中 / 左中 / 上中 / 右中 | 正 | 4 个旋转 |
| 同上 4 个位置 | 反（镜像） | 每个位置对应一个镜像 |

其中 **5 恒在正中**，**1 只出现在 4 个边中点**（永远到不了角）。

原因：旋转和镜像构成正方形的对称群，它把「边中点的数字」在边中点之间搬，「角上的数字」在角之间搬。洛书里 1 在边中点，所以它永远在边中点。

## 2. 各阶数量与增长

### 2.1 数量表

「本质类」指不含旋转镜像。

| 阶 | 本质类数 | 含 8 种朝向 | 怎么得到的 | 年份 |
|---|---|---|---|---|
| 3 | **1** | 8 | 可证明 | 古典 |
| 4 | **880** | 7,040 | 手工枚举（Frénicle de Bessy） | 1693 |
| 5 | **275,305,224** | ~2.2×10⁹ | 计算机计算（Schroeppel） | 1973 |
| 6 | **17,753,889,197,660,635,632** | ~1.4×10²⁰ | 计算机计算（Mino） | 2024 |
| 7 | **未知** | 未知 | 尚无结果 | — |

**注意 6 阶的年份是 2024**——它不是老结论。

### 2.2 为什么爆炸

三个量的增长阶完全不同：

| 阶 n | 格子数 n² | 约束数 2n | 约束覆盖率 2/n | 全排列 n²! |
|---|---|---|---|---|
| 3 | 9 | 6 | **66.7%** | 3.6×10⁵ |
| 4 | 16 | 8 | **50.0%** | 2.1×10¹³ |
| 5 | 25 | 10 | **40.0%** | 1.6×10²⁵ |
| 6 | 36 | 12 | **33.3%** | 3.7×10⁴¹ |

**格子按 n² 涨，约束只按 n 涨**，所以覆盖率从 67% 一路降到 33%。约束越来越松，解自然越来越多。

### 2.3 但每一阶其实更「稀有」

| 阶 | 幻方数 / 全排列 | 变化 |
|---|---|---|
| 3 | 2.8×10⁻⁶ | — |
| 4 | 4.2×10⁻¹¹ | ↓ 4.8 个数量级 |
| 5 | 1.8×10⁻¹⁷ | ↓ 6.4 |
| 6 | 4.8×10⁻²³ | ↓ 5.6 |

**绝对数量在暴涨，但占比在暴跌。** 每一阶都比上一阶更稀有——这两件事同时发生。

## 3. 4 阶：880 个本质解的完整枚举

### 3.1 方法

按行搜索 + 列和剪枝：

1. 预计算所有「4 个数、和为 34」的全排列（2,064 个候选行）
2. 逐行填，维护 `cols[4]` 增量列和，超过 34 立即剪枝
3. 填满 3 行后，第 4 行由列和反解（每列 `34 − 前三行之和`），检查无重复
4. 用 D4 群（4 旋转 × 2 镜像）对解去重，取字典序最小的作为规范形

### 3.2 结果

```
耗时 282s
原始解   7040 个   ← 恰好 = 880 × 8
本质类    880 个   ← 与 Frénicle 1693 的结论吻合
非法解      0 个
```

两处独立证据对上了：8 的倍数关系精确成立，本质类数精确落在 880。

### 3.3 数据格式

`data/fourth_order_880.json` 是一个数组，长度 880，每个元素是一个 4×4 的二维数组：

```json
[[[16,2,3,13],[5,11,10,8],[9,7,6,12],[4,14,15,1]], ...]
```

第一个元素是 Dürer 幻方。所有 880 个都已逐个验证：1–16 无重复、行列两对角线之和均为 34。

## 4. 5–7 阶：构造族与不可穷举

### 4.1 拉丁方叠加（适用于质数阶 5、7）

```
M[i][j] = A[i][j] + n·B[i][j] + 1
A = (a1·i + b1·j) mod n
B = (a2·i + b2·j) mod n
```

要求 A、B 都是**对角拉丁方**（行/列/两对角线皆为 0..n−1 的排列）且相互**正交**。判定条件：

```
a, b ≠ 0
a ± b ≢ 0 (mod n)
a1·b2 − a2·b1 ≢ 0 (mod n)
```

实测产出：5 阶 **32** 个、7 阶 **432** 个，全部验证为合法幻方。

**局限要说清**：这类幻方全部是 panmagic（泛对角）——因为 M 是 i、j 的线性函数，所有破对角线和必然相等。**它们结构同质，只差斜条纹方向，不能代表 275M 量级的全部多样性。**

### 4.2 6 阶的硬壁

6 阶**不存在正交拉丁方对**——这是 Euler 的 36 军官问题，Tarry 1901 年证明无解。拉丁方法对 6 阶从根上失效，只能用 LUX 之类的分块构造。

**规律**：n=2 和 n=6 是仅有的两个不存在正交拉丁方对的阶。

## 5. 后天八卦与洛书：是同一个事物吗

### 5.1 简短回答

**不是。** 它们是**一套坐标系 + 两种填充**：

```
九宫（空间框架，只有位置没有数）
  → 洛书（往九宫填 1–9）
  → 后天八卦（按方位把数贴到卦上）
```

### 5.2 时间线

| 时间 | 依据 | 内容 | 性质 |
|---|---|---|---|
| 先秦 | 《说卦传》 | 「帝出乎震…」后天八卦方位 | 文献 |
| 战国—汉初 | 《大戴礼记·明堂》 | 明堂九室（九宫雏形） | 文献 |
| **前 173 年** | **阜阳双古堆西汉墓太乙九宫占盘** | **九宫 + 数字的实物** | **考古实物** |
| 西汉末 | 《易纬·乾凿度》 | 「太一取其数以行九宫」 | 纬书，成说年代有争议 |
| 汉—北周 | 《数术记遗》及甄鸾注 | 「戴九履一，左三右七，二四为肩，六八为足，五居中央」 | 成书年代有争议 |
| 南宋 1275 | 杨辉《续古摘奇算法》 | 3–10 阶纵横图，首次系统研究幻方 | 确切 |

**「洛书」这个名字是宋代的**（陈抟传出图式、朱熹《周易本义》定型），图本身是汉代的。清代考据学（黄宗羲《易学象数论》、胡渭《易图明辨》）已经论证过：图式晚出，非上古。

### 5.3 配数的依据是方位，不是幻方性质

坎在北，洛书的 1 也在北 → 坎 = 1。整个过程只用「方位」一个依据，**从未使用「行列对角和等于 15」**。

那为什么配完恰好是幻方？因为洛书本身的设计原则已经蕴含了幻方性质：

1. **5 居中央**（3 阶幻方的必然）
2. **对宫互补**：1+9 = 2+8 = 3+7 = 4+6 = 10

这两条一确立，穿过中心的四条线自动都是 `5 + 10 = 15`。

### 5.4 巧合在哪

**在唯一性。**

3 阶幻方本质只有一个解，所以「后天八卦配洛书数」才能构成一个确定的等式。如果像 4 阶那样有 880 个解，古人配数时就会遇到「该配哪一个」的问题。

**而唯一性是数学事实，不是任何人设计的。**

## 6. 可视化

`index.html` —— 单文件、零依赖、可离线。手写 3D 投影（Canvas 2D），无 WebGL。

**功能**：

| 控件 | 说明 |
|---|---|
| 阶数 | 3 / 4 / 5 / 6 / 7 |
| 构型 | 4 阶 880 个全收录，可逐个翻或随机跳；5 阶 33 个、7 阶 433 个 |
| 朝向 | 4 个旋转 + 镜像开关（D4 群） |
| 弧高 | 真半圆 / 等高扁平 |
| 1→2 | 起上 / 起下（整条路径的相位） |

**画的是什么**：数字 1→n² 按数序连线，相邻两段交替从平面上方拱过、从下方穿过，形成一条上下穿梭的路径。

**几何约定**：平面固定 ±1.5，格距 `g = 3/n`（各阶视觉尺寸一致）。弧线参数方程：

```
P(t) = M − half·cos(πt)·u + h·sin(πt)·V
semi: h = half（真半圆，拱高 = 半径）
flat: h = 0.5g（所有弧等高）
```

**一个实测发现**：3–7 阶最大拱高基本稳定在 1.12–1.35（世界单位）。因为格距按 `3/n` 缩小，正好抵消段长按格数增长——所以「真半圆」在高阶不会失控。

## 7. 实际应用：诚实的说明

**幻方几乎没有工程应用。**

| 类别 | 有没有 | 说明 |
|---|---|---|
| 芯片 / 硬件 / 软件 | **没有** | 无主流系统依赖幻方 |
| 密码学 | **没有** | AES 的 S-box 来自有限域逆元 |
| 纠错码 | **没有** | LDPC / RS 码用稀疏图或有限域 |
| 实验设计 | **没有** | 用的是**正交表**（同族但不同物） |
| 数学教育 | 有 | 教约束满足、回溯搜索、对称性 |
| 文化装饰 | 有（仅 3 阶） | 古建、器物上的九宫图案 |

**为什么拉丁方到处在用，幻方没有？**

拉丁方的核心约束是**正交性**——保证「每对组合恰好出现一次」，这个性质有功能语义（可分离变量），所以能排实验、排赛程、做测试。

幻方的核心约束是**求和均衡**——它只是一个漂亮的巧合，保证不了任何事情。

**约束的类型决定了它能不能用。** 同样是一张填数格，一个管「分配得均匀」，一个管「加起来好看」。

## 8. 复现

```bash
# 3 阶：穷举，应得 8 个解、1 个等价类
python tools/enumerate.py --order 3

# 4 阶：全枚举，应得 7040 个解、880 个等价类（约 5 分钟）
python tools/enumerate.py --order 4 --out data/fourth_order_880.json

python tools/enumerate.py --verify data/fourth_order_880.json
```

纯标准库，Python 3.7+。不需要 numpy / pandas。
